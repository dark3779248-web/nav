# 一站直达 · 网址导航

经典 hao123 风格的个人/团队网址导航站，纯静态单文件，无需后端。

## 功能

- **9 大分类**：AI 工具、开发编程、设计灵感、效率办公、学习成长、新闻资讯、购物生活、影音娱乐、实用工具
- **三引擎搜索**：Google / 百度 / 必应 切换，记忆上次选择
- **收藏功能**：鼠标悬停卡片右上角 ☆，点击后置顶到"常用"栏
- **深色模式**：右上角 🌙 切换，跟随系统 + 本地保存
- **响应式布局**：手机端侧边栏变顶部横滑，卡片自动变单列
- **零依赖**：单个 HTML 文件，不需要构建，不需要数据库

## 部署

已部署在 Vercel，推送到 main 分支自动更新。

## 如何添加/修改网址

编辑 `index.html`，找到 `const CATEGORIES = [` 这段，在对应分类的 `sites` 数组里增减条目：

```js
{ n: "站点名", d: "一句描述", u: "https://网址.com", c: "#颜色" }
```

提交后 Vercel 自动重新部署。

## 本地预览

下载 `index.html`，双击用浏览器打开即可。
